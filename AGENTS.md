# AGENTS.md

Casa: home assistant for desktop and mobile, built once with Tauri 2, React and Tailwind. It controls Tapo plugs and Home Assistant entities, and maps the local network without sending data to the cloud.

## Stack

- Frontend: React 19, Vite, Tailwind 4, Zustand, TypeScript
- Desktop/mobile shell: Tauri 2 (Rust crate `casa_lib` in `src-tauri/`)
- Tooling: Bun (package manager and test runner), Biome (lint)

## Commands

```bash
bun install
bun run dev                              # browser, demo mode with a sample network
bun run tauri dev                        # desktop app, native scan and real providers
bun test                                 # pure logic tests (classifier, automation, sync)
bun run lint                             # Biome on src and scripts
bun run build                            # tsc --noEmit + production bundle in dist/
bun run tauri build --debug --no-bundle  # debug binary in src-tauri/target/debug
bun run gen:oui                          # regenerate src/data/oui-iot.json from the IEEE list
bun run screenshots                      # regenerate .github/assets/screenshots in demo mode
```

## Structure

- `src/core/` - classifier and device logic (MAC vendor, open ports, HTTP banner)
- `src/data/` - `oui-iot.json`, generated by `gen-oui`
- `src/pages/`, `src/ui/` - screens and components
- `src/state/` - Zustand stores
- `src/platform/` - bridge between the web UI and Tauri commands
- `src-tauri/` - Rust side: native scan, credential vault, capabilities
- `scripts/` - `gen-oui.ts`, `readme-screenshots.ts`, `scan-lan.ps1`
- `research/` - provider and platform research notes

## Conventions

- `src/core/` has no Tauri imports, so its `bun test` suites run without a desktop; device access goes through `src/platform/`.
- Lint: `bun run lint` (Biome) on `src` and `scripts`.
- CI: `central-validate.yml`, `central-security.yml` and `sast.yml` call reusable workflows from `juninmd/base-actions`.

## Gotchas

- Credentials for Tapo and Home Assistant live in the OS vault. Never commit tokens, passwords or device secrets.
- `research/lan-scan.json` and `research/00-mapa-da-rede.md` are gitignored on purpose: they hold real MACs and hostnames. Keep them local.
- `src/data/oui-iot.json` is generated; regenerate with `bun run gen:oui`, do not hand-edit.
- Use `bun` only (`bun.lock` is the lockfile); do not add `package-lock.json` or `yarn.lock`.
- `bun run dev` runs demo data only; real device behavior needs `bun run tauri dev`.
